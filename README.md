# BabbleLab-Freestyle · 乱讲

从一句人话，顺着歪理讲到天边。

你说：“怎么还没到周五？”

它可以接：“周五在路上了，拎着两大袋周四，走不快。”

Freestyle 是一个中文为主、也能用英文的即兴创作技能。从 [BabbleLab-RenHua](https://github.com/yn-fan/BabbleLab-RenHua) 的自然表达出发，它会多做一件事：把眼前的小事想歪一点，再认真追下去。可以是网友式的一句接梗，也可以越侃越远，讲成一场 PPT 乱讲。

## 可以怎么用

| 想写什么 | 可以这样提要求 |
|---|---|
| 一句抖机灵 | “朋友说周五怎么还没到，帮我接一句，别解释。” |
| 侃大山、满嘴跑火车 | “洗衣机脱水时往旁边挪，随便扯扯，越讲越玄。” |
| 荒诞标题和脑洞 | “给我 12 个乱讲 PPT 题目，每个都能往下讲，别全是职场梗。” |
| PPT Karaoke | “题目是冰箱迁徙，按我给的三张图逐页讲，认真一点，歪理大胆一点。” |
| 有事实的介绍加点趣味 | “这段产品介绍写活一点，价格、功能和限制都保留。” |
| 自由奇想 | “傍晚的影子在忙什么？不用搞笑，想到哪里说到哪里。” |

“再野一点”“别太油”“冷一点”“嘴碎一点”“一句就够”都能直接说，不必先选一堆参数。英文请求就按英文的说法写。

## 能跑多远

同一个“我家很小”，可以只拐一下：

> 朋友问客厅在哪，我往旁边让了半步。

也可以往远处讲：

> 我家没有走廊，主要靠转念。刚想去厨房，人已经到了。朋友来参观，我说慢一点，你刚才那个逗号把卧室走完了。

还可以把房子折起来：

> 上周量面积，卷尺刚拉开就伸进了邻居家。只好把房子折起来量，发现折痕里面藏着一间衣帽间。现在我们一家住折痕里，客厅摊开晒着。邻居路过，以为那是一张户型图。

这些是本项目的原创练习。更多短回复、长段侃聊、真实资料加趣和英文即兴，见[乱讲几段](examples/showcase.md)。

## 安装

```bash
git clone https://github.com/yn-fan/BabbleLab-Freestyle.git
cd BabbleLab-Freestyle
```

Codex：

```bash
python3 tools/install.py --to ~/.agents/skills
```

```text
$babblelab-freestyle 为什么我家那把椅子看起来比我更想辞职？放开讲，直接给作品。
```

Claude Code：

```bash
python3 tools/install.py --to ~/.claude/skills
```

```text
/babblelab-freestyle 给我十个适合乱讲 PPT 的题目，跨远一点，少用公司黑话。
```

安装器需要 Python 3.9+，只复制完整技能目录；已有同名目录会停止。其他支持 `SKILL.md` 的工具，可导入整个 [skills/babblelab-freestyle](skills/babblelab-freestyle) 文件夹。安装位置参考 [Codex](https://developers.openai.com/codex/skills/) 和 [Claude Code](https://code.claude.com/docs/en/skills) 官方说明。

不需要先装 RenHua，也没有必需的外部服务。作品由使用技能的模型生成，效果会受模型、上下文和题目影响；仓库本身没有接入付费模型或在线生成接口。

## 它怎么乱讲

先抓一个具体东西：水管、袜子、面条、图上的拐点，或者对方刚说的一个词。给它一个歪解释，再看看这个解释成立以后，接下来会发生什么。

于是洗衣机的震动可以被讲成散步，水管让它走不远，贴在玻璃上的袜子又把它变成公交车。每次转弯都有来路，后面的事还会继续改变前面的理解。

技能里有字面误读、尺度变化、规则借用、关系反转、岔路和回扣等方法，按题目选用。短回复可以一句结束；长独白也可以停在一个怪画面上。没有规定每段必须三个包袱，也不要求最后升华。

明确要胡说八道或编故事，就放开创造设定。给真实介绍加趣味时，数字、日期、承诺和限制照原文保留。普通润色交给 RenHua；想认真回答的时候，直接说“别加戏”。两者可以同时安装。

## 灵感从哪里来

我们读了 PPT Karaoke 网站的玩法和出题说明、Hoopla 的即兴教学，也通过 B 站公开接口核对了部分中文乱讲标题和短回复。例如《从三文鱼到巧乐兹》这样的题面把两个具体端点交给讲者；“低头疯狂记笔记”这样的回复，用一个动作接住了表演。

首版取的是这些表达方法：接住对方的设定，沿一个怪点追后果，从小细节岔开，再让它换个用途回来。没有搬运整套幻灯片，也没有把生成段子当成网友原话。

- [中文标题与短回复研究](docs/research/chinese-banter.md)：实际取得的题目、短摘录、作品与回复链接。
- [PPT Karaoke 与英文即兴研究](docs/research/ppt-improv.md)：6 个实际阅读的第一方页面及适用边界。
- [设计取舍](docs/design.md)：怎样从保守编辑改成自由创作。

本轮未观看这些演讲的视频，也未取得逐字稿；题目研究不等于分析了讲者的现场发挥。“喷空”“侃大山”“摆龙门阵”作为创作方向使用，不把几个样本说成某地区的统一说话方式。
