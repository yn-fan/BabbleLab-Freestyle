# BabbleLab-Freestyle · 苏州乱讲实验室

**别人还在想让 AI 说人话，我们的 AI 已经开始满嘴跑火车了。**

这里是苏州乱讲实验室。我们做乱讲 PPT、即兴表演和即兴辩论，也把真人现场的脑洞、接话和抬杠方式，整理成一个能直接使用的 Skill。

用途很朴素：把一句无趣的话，换个有意思的说法。可以改群聊、开场白和日常介绍，也可以递给它一张图、一句台词、一个辩题，看看这句话还能往哪里走。

## 乱讲，也是一门正经手艺

刘震云的《一地鸡毛》从一块馊豆腐写起，把人带回日常的琐碎。至于“喷空”，更明确的作品线索在《一句顶一万句》和《一日三秋》。相关文学评论转引《一句顶一万句》中的一句：“你一言我一语，把整个事情搭起来。”有人起头，有人接话，事情未必要发生过，前后却得搭得上。[出处与核查说明](docs/research/playful-speech.md#刘震云与喷空)

这类乐趣并不只在一张方桌旁出现。巴斯克的 **bertsolaritza** 把题目唱成有格律、押韵的即兴诗；巴西的 **Repente** 常由两名唱者轮流发挥，听众也能递题。它们是各有规矩的口头传统，题材可以幽默，也可以严肃。自由发挥，原来也可能是门技术活。[传统与规则](docs/research/playful-speech.md#不同地方怎样玩)

现代玩法又长出别的样子。日本《笑点》的大喜利会给一句设定，再由主持人追问，把回答拐向下一句。Toastmasters 把提前准备的夸张故事 **Tall Tales**，与上场才知道题目的 **Table Topics** 分成不同比赛。一个练如何把离奇故事讲成立，一个练眼前有题就能开口。它们与喷空可以比较，却各有各的来路。

还有一些舞台、节目和书，也让我们愿意把话再往下接：

- **《奇葩说》的往期辩论**：像“大城床 OR 小城房”这样的题目，同一个选择，换个站位就要拿出另一套理由。
- **乱讲 PPT**：题目和图片递到面前，当场替它们解释关系。图已经翻了，思路还可以继续追。
- **即兴表演的 YES, AND**：先接住搭档已经给出的设定，再添一个动作、细节或后果，让下一句有地方落脚。不必每句话都说“是的，而且”，关键是把戏一起往前演。[方法来源](https://www.hooplaimpro.com/resource/yes-and)
- **大张伟的《万物自洽法则》**：目录里有一句“自己挖坑自己跳，爬不出来自己笑”。有时换个角度，也包括把自己放进笑话里。

形式不同，我们喜欢的趣味相通：换一个站位，原本僵住的话，就有了继续说下去的余地。[节目与书目](docs/research/playful-speech.md#节目与书目)

## 地球 Online，大家都是来玩的

这个世界已经有不少事情，需要认真填写、按时提交、反复确认。我们愿意另外留一张桌子，说几句不以完成任务为目的的话。

“差不多得了”是本实验室给较劲留的一个出口。该交的稿照常交，该解决的问题照常解决；闲话可以暂时不交心得体会。你不必先变成一个特别会说话的人，才有资格加入。

给一句话、一张图，或者一个你自己也没想明白的念头。先玩一会儿，不耽误地球自转。

## 刷新一下你的发言

你原本想说：

> 怎么还没到周五？

刷新一下：

> 周五在路上了，拎着两大袋周四，走不快。

你原本想说：

> 我家很小。

刷新一下：

> 朋友问客厅在哪，我往旁边让了半步。

再放飞一点：

> 我家没有走廊，主要靠转念。刚想去厨房，人已经到了。朋友来参观，我说慢一点，你刚才那个逗号把卧室走完了。

这些是项目原创示例。更多[原话与刷新后的对照](examples/refresh-your-lines.md)，以及[长段侃聊、英文即兴和奇想](examples/showcase.md)，可以接着看。

## 真人的脑洞，长这样

黑糖的置顶互动让大家“用下属的语气说句话”。有人申请出差报销“五个亿”，作者接：

> 你去地府出差了？

有人说“You are fired”，作者接：

> 我是火？

这是[黑糖的公开互动](https://www.xiaohongshu.com/explore/673b40cc0000000002038ac8)。我们把这种接话的转弯放进了技能。

[《小设计找妈妈》](https://www.xiaohongshu.com/explore/6ad09578000000001303f04b)借了“找妈妈”的童话，一路找审美、找预算、找一个愿意理解设计师的人。等到一句“妈妈，尾款呢？”，童话也得结账。这种能讲长一点、最后又落回具体处境的办法，技能里也有。

幻灯片继续往后翻，解释也要跟上。[《阳澄湖水怪是真实存在的！》](https://www.xiaohongshu.com/explore/689f2c5a000000001b0337a4)把越来越不搭的动物图片接进同一套“伪装、进化”的说法；[《东方之门的航空使命》](https://www.xiaohongshu.com/explore/68a81390000000001d029937)边指图、边改解释，连新出现的“大脑”图也能接回前面。谁发布、谁发言、哪些片段已经核对，都在[现场取材记录](docs/research/field-recordings.md)里。

## 这一局，想怎么玩

| 玩法 | 你可以拿它做什么 |
|---|---|
| 乱讲 PPT | 给一张不搭的图找歪理，把上一页说过的话圆到下一页；也能帮你出一批有得讲的题目 |
| 即兴表演 | 给角色和场景，和它一来一回地接戏；接受已经发生的事，再给对方一个新麻烦 |
| 即兴辩论 | 给立场或对方上一句，它接住那个论点抬杠，讲完把话交回来 |
| 即兴演讲 | 临时给一个题目，抓住一句主张，用具体例子说清楚，再找一个落点 |
| 喷空接龙 | 你起个话头，它接一段；人、物件和麻烦可以越长越奇怪，前后仍接得上 |
| 说唱与押韵 freestyle | 接住题目和给定的词，写有意思、有韵脚的说唱文字稿，按需要调整节奏和换韵 |

群聊、开场白、吐槽、朋友间的回应和日常介绍，都能拿来试。“一本正经一点”“别太油”“冷一点”“再野一点”“只要一句”直接说，口吻和篇幅可以跟着调。

乱讲实验室的即兴辩论，说完把蓝色手柄一推，话就到了对面；现场活动的投票靠观众欢呼。技能也沿用这个交接习惯：接完自己这一轮，把下一句留给你。

## 把第一句递过来

```text
$babblelab-freestyle 把这句发言刷新得有趣一点，适合发群里，别写长：……
```

```text
$babblelab-freestyle 即兴接戏。你是保安，我是给月亮送外卖的人。
我说：“师傅，月亮留的门牌号怎么在你后脑勺上？”只接你这一轮。
```

```text
$babblelab-freestyle 即兴辩论。对方说：“午睡就是偷走下午的时间。”
你支持午睡，接住他这句话反驳，别写成议论文。
```

```text
$babblelab-freestyle 我刚讲完“冰箱正在向南迁徙”，下一页突然是一盆仙人掌。
帮我接过去，认真讲歪理。
```

```text
$babblelab-freestyle 临时发言，约一分钟。题目：朋友聚会为什么值得留一个空位？
口语一点，有具体例子，别写成议论文。
```

```text
$babblelab-freestyle 用晚高峰、雨伞、便利店写8行中文rap。
两行一组押韵，意思要接得上，只给文字。
```

给现成发言加趣味，原意、数字、日期和条件要留住。周五交稿，放飞以后也得是周五，不能顺嘴交给下个朝代。明确要胡说八道、编故事或表演，就可以大胆创造设定。想认真回答时说“别加戏”；英文也可以用。

方法按场景选：接戏先听清搭档给了什么，演讲先想清要说哪件事，喷空让故事接着长，说唱再处理韵脚、重音和呼吸。普通的“放开讲”不会自动变成 rap；没有实际伴奏时，节拍标记只是文字排练建议。[技法与原创练习](examples/technique-lab.md)

## 安装

```bash
git clone https://github.com/yn-fan/BabbleLab-Freestyle.git
cd BabbleLab-Freestyle
```

Codex：

```bash
python3 tools/install.py --to ~/.agents/skills
```

Claude Code：

```bash
python3 tools/install.py --to ~/.claude/skills
```

Claude Code 用 `/babblelab-freestyle` 调用。其他支持 `SKILL.md` 的工具，可导入整个 [skills/babblelab-freestyle](skills/babblelab-freestyle) 文件夹。安装器需要 Python 3.9+；已有同名目录时会停止，不会覆盖。

不需要先装其他技能。作品由你使用的模型生成，效果会受模型和上下文影响。安装路径参考 [Codex](https://developers.openai.com/codex/skills/) 与 [Claude Code](https://code.claude.com/docs/en/skills) 官方说明。

## 这股劲儿，来自苏州

小红书 **@乱讲实验室**、**@黑糖不是黑桃** 的创作者，也是这个项目的发起人。这里的脑洞从苏州的创作和现场活动里长出来：有人递来一个念头，另一个人接住，拐了个弯，再递出去。前面的文学、口头传统和节目是可供参照的读物与玩法；我们自己的现场，从苏州这张桌子开始。

素材包括创作者提供的品牌原文、现场玩法，以及已经读到的公开图文、作者回复和录像画面字幕；新写的练习另有标注，见[创作者材料](docs/research/creator-materials.md)。真人说过的，认原作者；技能新编的，别往真人嘴里塞。这是一套创作说明，没有把模型重新训练成谁。
