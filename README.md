# BabbleLab-Freestyle · 苏州乱讲实验室

**别人还在想让 AI 说人话，我们的 AI 已经开始满嘴跑火车了。**

AI 一认真，很容易把“随便聊聊”办成一个项目。你刚说今天有点累，它已经替你排好了三个阶段。

这里是苏州乱讲实验室。我们玩乱讲 PPT、即兴表演和即兴辩论，把真人现场的脑洞、接话和抬杠经验，做成了这份 Skill。你递一句话，它往下接；递一张不搭的图，它得想办法圆。

对，我们把自由发挥写成了规则。也没那么矛盾，自由泳还得学换气。

> 沉着冷静，即使一无所知。
>
> ——乱讲实验室

## 乱讲，也是一门正经手艺

《一地鸡毛》从一块馊豆腐写起。豆腐可以扔，日子还得过。“喷空”的明确线索，则在刘震云的《一句顶一万句》和《一日三秋》。文学评论转引《一句顶一万句》：“你一言我一语，把整个事情搭起来。”故事可以没发生过，下一句可不能假装没听见上一句。[出处](docs/research/playful-speech.md#刘震云与喷空)

巴斯克的 **bertsolaritza** 按格律、押韵即兴吟唱；巴西的 **Repente** 常由两人轮流发挥，听众也能递题。这两种口头传统各有规矩，能幽默，也能严肃。[传统与规则](docs/research/playful-speech.md#不同地方怎样玩)

现代舞台和社群也有不同玩法。日本《笑点》的大喜利用主持人的追问接出下一句。Toastmasters 则把提前准备的夸张故事 **Tall Tales**，与上场才知道题目的 **Table Topics** 分开比赛。来路各算各的，手艺可以放一桌聊。

我们还从这些地方找乐子：

- **《奇葩说》的往期辩论**：“大城床 OR 小城房”，换个立场，就要讲出另一套理由。
- **乱讲 PPT**：新图来了，刚才那套理论立刻面临考验。别急，给它补一条歪理，看看还能不能走。
- **即兴表演的 YES, AND**：先接住，再添一点。月亮来借伞，先铺块毛巾，免得它把潮汐滴一地。[方法来源](https://www.hooplaimpro.com/resource/yes-and)
- **大张伟的《万物自洽法则》**：目录里有一句“自己挖坑自己跳，爬不出来自己笑”。[节目与书目](docs/research/playful-speech.md#节目与书目)

## 地球 Online，大家都是来玩的

吃完一顿饭，不一定要带着三个结论回家。带走一个新梗，记住一个怪人，也算没白来。

该交的稿照常交。至于每句话都得有用、每次开口都要出彩——差不多得了。

## 刷新一下你的发言

**原话：** 我有点饿了。

> 我现在看这份 PPT，已经开始琢磨哪一页适合蘸酱。

**原话：** 我家很小。

> 朋友问客厅在哪，我往旁边让了半步。

**再放飞一点：**

> 我家没有走廊，主要靠转念。刚想去厨房，人已经到了。朋友来参观，我说慢一点，你刚才那个逗号把卧室走完了。

以上是项目原创示例。更多[前后对照](examples/refresh-your-lines.md)与[长段侃聊、英文即兴](examples/showcase.md)。

## 真人的脑洞，长这样

黑糖让大家“用下属的语气说句话”。有人要报销“五个亿”，他回：

> 你去地府出差了？

有人说“You are fired”，他回：

> 我是火？

这两句出自[公开互动](https://www.xiaohongshu.com/explore/673b40cc0000000002038ac8)。

[《小设计找妈妈》](https://www.xiaohongshu.com/explore/6ad09578000000001303f04b)把设计师对审美、预算和理解的期待搬进童话。直到一句“妈妈，尾款呢？”——童话也得结账。

台下已经有人看着你，下一页还不肯配合。这时候，歪理也得有点续航：

- [《阳澄湖水怪是真实存在的！》](https://www.xiaohongshu.com/explore/689f2c5a000000001b0337a4)：动物图一张张换，“伪装、进化”这套解释接着用。
- [《东方之门的航空使命》](https://www.xiaohongshu.com/explore/68a81390000000001d029937)：遇到“大脑”图，给前面的故事换个解释，再接回来。

发布者、实际发言者与核对范围，分别记在[现场取材记录](docs/research/field-recordings.md)里。

## 这一局，想怎么玩

| 玩法 | 用法 |
|---|---|
| 乱讲 PPT | 拿图现编、接住意外，也能先出题 |
| 即兴表演 | 给角色和场景，让对方有戏可接 |
| 即兴辩论 | 站住一边，接对方的论据，讲完交棒 |
| 即兴演讲 | 有主张、有例子，知道在哪句停 |
| 喷空接龙 | 你起头，它续事。想象走远，人和事别丢 |
| 说唱与押韵 freestyle | 押得上，也得说得通；交付说唱文字稿 |

“一本正经一点”“别太油”“冷一点”“再野一点”“只要一句”——直接说，不用先写需求文档。

乱讲实验室的现场辩论用蓝色手柄交接发言，活动投票靠观众欢呼。技能借的是接话的习惯：这一轮接完，下一句留给你。

## 开始用

### 豆包、DeepSeek 等聊天 AI

先复制这份[聊天版指令](prompts/chat-starter.md)，再贴你的原话或题目。新对话里也先贴规则，不用安装，也不需要 Python。

聊天版自包含核心方法；完整技能包还有更多技法和来源。不同模型的表现会有差异，目前未在豆包、DeepSeek 客户端逐一实测。

### Codex、Claude Code 等技能客户端

```bash
git clone https://github.com/yn-fan/BabbleLab-Freestyle.git
cd BabbleLab-Freestyle
```

Codex：

```bash
python3 tools/install.py --to ~/.agents/skills
```

Claude Code：

```bash
python3 tools/install.py --to ~/.claude/skills
```

安装后，Codex 用 `$babblelab-freestyle`，Claude Code 用 `/babblelab-freestyle` 调用。其他支持 `SKILL.md` 的工具，可导入整个 [skills/babblelab-freestyle](skills/babblelab-freestyle) 文件夹。

安装器需要 Python 3.9+，已有同名目录会停止，不会覆盖。不依赖其他技能。安装路径参考 [Codex](https://developers.openai.com/codex/skills/) 与 [Claude Code](https://code.claude.com/docs/en/skills) 官方说明。

## 把第一句递过来

普通聊天先贴聊天版指令，再发下面的请求；已安装技能的客户端，在请求前加上对应调用名。

```text
把这句发言刷新得有趣一点，适合发群里，别写长：……
```

<details>
<summary>接戏、辩论、演讲、说唱，再试几个</summary>

```text
即兴接戏。你是保安，我是给月亮送外卖的人。
我说：“师傅，月亮留的门牌号怎么在你后脑勺上？”只接你这一轮。
```

```text
即兴辩论。对方说：“午睡就是偷走下午的时间。”
你支持午睡，接住他这句话反驳，别写成议论文。
```

```text
我刚讲完“冰箱正在向南迁徙”，下一页突然是一盆仙人掌。
帮我接过去，认真讲歪理。
```

```text
临时发言，约一分钟。题目：朋友聚会为什么值得留一个空位？
口语一点，有具体例子，别写成议论文。
```

```text
用晚高峰、雨伞、便利店写8行中文rap。
两行一组押韵，意思要接得上，只给文字。
```

</details>

改写真实材料，保留原意、数字、日期和条件。周五交稿，放飞以后也得是周五，不能顺嘴交给下个朝代。明确要编故事，就放开编；想认真回答，就说“别加戏”。英文也可以。

普通的“放开讲”不会自动变 rap。没有实际伴奏，节拍标记只是文字排练建议。[技法与原创练习](examples/technique-lab.md)
